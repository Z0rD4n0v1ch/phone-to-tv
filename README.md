# Экран на ТВ (PhoneToTv)

Трансляция экрана Android-телефона на Android TV-приставку по Wi‑Fi.
Картинка идёт на телевизор, звук остаётся на телефоне. Без сторонних библиотек — только Android SDK.

**Один APK** ставится и на телефон, и на приставку. Приложение работает в двух режимах:

| Режим | Где | Что делает |
|---|---|---|
| **Передавать** | телефон | захватывает экран, сжимает в H.264 и отправляет по сети |
| **Принимать** | ТВ-приставка (или другой телефон/планшет) | принимает поток, декодирует аппаратно и показывает на весь экран |

На ТВ-приставке сразу включается приём. На телефоне при первом запуске приложение спросит,
что делать, и запомнит выбор. Сменить режим — кнопка «Сменить режим» на телефоне или «Назад» на экране приёма.

Android 7.0 и новее. **Скачать:** [последний релиз](https://github.com/Z0rD4n0v1ch/phone-to-tv/releases/latest).
Приложение также есть в витрине [Tools Box](https://z0rd4n0v1ch.github.io/tools-box/#phone-to-tv).

## Возможности

- Поиск приставки в сети одной кнопкой или ввод IP вручную.
- Настройки качества: 480p / 720p / 1080p, битрейт от 2 до 16 Мбит/с, 30 или 60 кадров/с.
  Если кодер телефона не тянет выбранное, разрешение снижается само.
- Поворот телефона: картинка на ТВ перестраивается без переподключения.
- Автопереподключение: при обрыве Wi‑Fi телефон сам подключается снова, а если роутер
  выдал приставке новый IP — находит её поиском и запоминает новый адрес.
- Остановка кнопкой в приложении или «Стоп» в уведомлении.

## Как пользоваться

1. Телефон и приставка — в **одной Wi‑Fi сети**.
2. На приставке запустите «Экран на ТВ» — включится приём, на экране появится её IP.
3. На телефоне откройте «Экран на ТВ», выберите «Передавать экран», нажмите «Найти приставку в сети» (или введите IP).
4. Выберите качество, нажмите «Начать трансляцию» и подтвердите запрос на захват экрана.

Версии на телефоне и приставке должны совпадать: обновляйте приложение на обоих устройствах.

## Установка

Один и тот же файл `PhoneToTv-*.apk`:
- **Телефон:** откройте APK и разрешите установку из этого источника.
- **Приставка:** запишите APK на флешку и откройте в файловом менеджере
  (например, X-plore), или по сети: `adb connect <IP>` → `adb install PhoneToTv-*.apk`.

Старые отдельные приложения «Экран на ТВ» (передатчик) и «Приём с телефона» удалите — они больше не нужны.
Если раньше стояла версия, собранная в Android Studio, тоже удалите её перед установкой версии с GitHub —
у них разные ключи подписи, и система не даст поставить одну поверх другой.

## Сборка у себя

Android Studio (Ladybug или новее) → File → Open → папка проекта → Build → Generate APKs.
Или в терминале: `.\gradlew assembleDebug` (Windows) / `./gradlew assembleDebug`.
APK: `app/build/outputs/apk/debug/app-debug.apk`.

Нужны JDK 17+ (в Android Studio уже есть), Gradle 9.6 и Android Gradle Plugin 9.5 — скачиваются сами.

## Выпуск новой версии

Один раз:
1. Создайте на GitHub пустой публичный репозиторий **phone-to-tv** (без README).
2. `bash make-key.sh` — создаст постоянный ключ подписи и подскажет, какие 4 секрета добавить
   в Settings → Secrets and variables → Actions. Без ключа APK тоже соберутся, но каждое
   обновление придётся ставить с удалением старой версии.

Каждый раз:
```
bash release.sh 1.1 "Что нового"
```
Скрипт выложит код и поставит тег `v1.1`. GitHub Actions соберёт APK (3–6 минут) и создаст релиз
с описанием. Tools Box сам покажет новую версию и кнопки скачивания.

Просто выложить код без релиза: `bash sync.sh "сообщение"`.

## Как это устроено

```
Телефон                                              ТВ-приставка
MediaProjection → VirtualDisplay → MediaCodec (H.264) → TCP :5000 → MediaCodec → SurfaceView
UDP-широковещание :5001  "PTV_DISCOVER"  ◄────────────► ответ "PTV_HERE:<имя>"
```

Протокол (big-endian): заголовок `MAGIC, width, height`, затем пакеты `flags, ptsUs, size, data`.
Флаги: 1 — SPS/PPS, 2 — ключевой кадр, 4 — смена размера (данные: width, height). Подробно — в `Protocol.kt`.

Код — в `app/src/main/java/com/example/phonetotv/`:

| Файл | Что внутри |
|---|---|
| `LauncherActivity.kt` | точка входа: выбор режима, на ТВ — сразу приём |
| `SenderActivity.kt` | режим «Передавать»: адрес, поиск, качество |
| `CastService.kt` | захват, кодирование, отправка, поворот, переподключение |
| `Quality.kt` | варианты качества |
| `Discovery.kt` | поиск приставки в сети |
| `ReceiverActivity.kt` | режим «Принимать»: приём, декодирование и показ на экране |
| `.github/workflows/release.yml` | сборка APK и релиз по тегу |

## Ограничения

- Звук не передаётся — он остаётся на телефоне.
- Приложения с защитой (банки, Netflix и т. п.) система показывает чёрным — это ограничение Android.
- Поток не шифруется — используйте только в домашней сети.
- Если поиск не находит приставку, роутер может блокировать широковещание (часто в гостевых сетях) — введите IP вручную.
