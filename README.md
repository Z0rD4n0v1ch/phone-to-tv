# Экран на ТВ

Трансляция экрана Android-телефона на Android TV-приставку по Wi‑Fi. Картинка идёт на телевизор,
звук — на телефоне или на ТВ, как выберете. Один APK для обоих устройств: на приставке сразу включается приём,
на телефоне — передача. Бесплатно, без рекламы, Android 7.0 и новее.

Скачать: [последний релиз](https://github.com/Z0rD4n0v1ch/phone-to-tv/releases/latest) · также в [Tools Box](https://z0rd4n0v1ch.github.io/tools-box/#phone-to-tv)

## Возможности

- Подключение по QR-коду с экрана приставки, поиском в сети или по IP.
- PIN при первом подключении телефона — чужой телефон в сети не выведет ничего на ваш экран.
- Звук на телевизоре (Android 10+), если приложение разрешает его передачу.
- Качество: 480p / 720p / 1080p, 2–16 Мбит/с, 30 или 60 кадров/с, автоподбор при слабом Wi‑Fi.
- Пульт ТВ управляет телефоном: пауза, перемотка, громкость.
- Индикатор на ТВ: кадры, битрейт, задержка сети.
- Картинка «вписать» или «заполнить экран»; поворот телефона без переподключения.
- Плитка в шторке уведомлений и подключение сразу при открытии.
- Второй телефон может подключиться — приставка спросит, принять ли его.
- Автозапуск на приставке при включении, автопереподключение и автообновление.

## Как пользоваться

1. Телефон и приставка — в одной сети.
2. На приставке откройте «Экран на ТВ» — появятся QR-код и PIN.
3. Отсканируйте QR-код камерой телефона (или на телефоне выберите «Передавать экран» → «Найти приставку»).

Пульт во время трансляции: OK — пауза, ◄ ► — перемотка, ▲ ▼ — громкость телефона, удерживайте OK — индикатор.
Версии на телефоне и приставке должны совпадать.

## Структура

```
app/src/main/java/com/example/phonetotv/
  LauncherActivity.kt   выбор режима; на ТВ — сразу приём
  SenderActivity.kt     режим «Передавать»: адрес, поиск, качество
  CastService.kt        захват экрана, H.264, отправка, поворот, переподключение
  ReceiverActivity.kt   режим «Принимать»: экран ожидания с QR и PIN, показ, звук, пульт
  CastTileService.kt    плитка в шторке уведомлений
  BootReceiver.kt       автозапуск на приставке
  QrCode.java           генератор QR-кода
  Updater.kt            автообновление из релизов GitHub
  Protocol.kt           протокол: рукопожатие, видео, звук, пульт (TCP :5000, поиск UDP :5001)
.github/workflows/release.yml   сборка APK и релиз по тегу
```
