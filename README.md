# Экран на ТВ

Трансляция экрана Android-телефона на Android TV-приставку по Wi‑Fi. Картинка идёт на телевизор,
звук остаётся на телефоне. Один APK для обоих устройств: на приставке сразу включается приём,
на телефоне — передача. Бесплатно, без рекламы, Android 7.0 и новее.

Скачать: [последний релиз](https://github.com/Z0rD4n0v1ch/phone-to-tv/releases/latest) · также в [Tools Box](https://z0rd4n0v1ch.github.io/tools-box/#phone-to-tv)

## Возможности

- Поиск приставки в сети одной кнопкой или ввод IP вручную.
- Качество: 480p / 720p / 1080p, битрейт 2–16 Мбит/с, 30 или 60 кадров/с.
- Поворот телефона без переподключения.
- Автопереподключение при обрыве Wi‑Fi, даже если у приставки сменился IP.
- Автообновление из релизов GitHub.

## Как пользоваться

1. Телефон и приставка — в одной Wi‑Fi сети.
2. На приставке откройте «Экран на ТВ» — на экране появится её IP.
3. На телефоне выберите «Передавать экран», найдите приставку и нажмите «Начать трансляцию».

Версии на телефоне и приставке должны совпадать.

## Структура

```
app/src/main/java/com/example/phonetotv/
  LauncherActivity.kt   выбор режима; на ТВ — сразу приём
  SenderActivity.kt     режим «Передавать»: адрес, поиск, качество
  CastService.kt        захват экрана, H.264, отправка, поворот, переподключение
  ReceiverActivity.kt   режим «Принимать»: приём и показ на экране
  Updater.kt            автообновление из релизов GitHub
  Protocol.kt           формат потока (TCP :5000, поиск UDP :5001)
.github/workflows/release.yml   сборка APK и релиз по тегу
```
